A one-line autocorrect fail: a thank-you text to Grandma takes a very wrong turn, then tries desperately to walk it back. Autocorrect swaps "sweater" for "vibrator", and the sender's panicked all-caps correction only makes the slip harder to unsee.

## Run it

```sh
python3 main.py
```

It prints the entry and writes it to `/output/entry.txt`.
